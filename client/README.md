# Finance Tracker — Client

React 19 frontend for the Finance Tracker app. See the [root README](../README.md) for full documentation, setup instructions, and feature overview.

## Dev

```bash
npm run dev      # start Vite dev server on port 5173
npm run build    # type-check + production build
npm run lint     # ESLint
```

The client expects the backend running on `http://localhost:3001`. Override with a `VITE_API_URL` environment variable.
